# Program 14 - Nested Class

## Aim

To implement a nested class in C++.

## Concept Used

* Nested Class
* Outer Class
* Inner Class
* Object Creation

## Description

This program demonstrates a class defined inside another class.

The `Department` class is declared inside the `University` class. The nested class is used to display the department name.

## Expected Output

```text
Department: AI & Data Science
```

## Learning Outcome

This program helps in understanding how a class can be declared inside another class and used when the functionality is closely related.
