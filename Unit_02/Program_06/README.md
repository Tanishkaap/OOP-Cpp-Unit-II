# Program 06 - Multiple Inheritance

## Aim

To implement multiple inheritance in C++.

## Concept Used

* Multiple Inheritance
* Multiple Base Classes
* Derived Class

## Description

This program demonstrates multiple inheritance where one derived class inherits from two different base classes.

The `Student` class inherits from both `Academic` and `Sports`.

The marks from both areas are combined to calculate the student's total marks.

## Learning Outcome

This program helps in understanding how a single derived class can inherit properties and functions from more than one base class.
