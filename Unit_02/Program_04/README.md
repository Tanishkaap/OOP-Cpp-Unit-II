# Program 04 - Multilevel Inheritance

## Aim

To implement multilevel inheritance in C++.

## Concept Used

* Multilevel Inheritance
* Base Class
* Intermediate Class
* Derived Class
* Constructors

## Description

This program demonstrates inheritance through multiple levels.

The `Person` class is the base class. `Employee` inherits from `Person`, and `Manager` further inherits from `Employee`.

This creates a three-level inheritance hierarchy.

## Expected Output

```text
Name: Ravi
Employee ID: 501
Team Size: 8
```

## Learning Outcome

This program helps in understanding how a class can inherit from another derived class to form a multilevel inheritance structure.
