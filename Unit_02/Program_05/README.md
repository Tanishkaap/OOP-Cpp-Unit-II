# Program 05 - Hierarchical Inheritance

## Aim

To implement hierarchical inheritance in C++.

## Concept Used

* Hierarchical Inheritance
* Base Class
* Multiple Derived Classes

## Description

This program demonstrates hierarchical inheritance where multiple derived classes inherit from a single base class.

The `Vehicle` class is the base class, while `Car` and `Bike` are derived classes.

Both classes can use the functionality provided by the `Vehicle` class.

## Learning Outcome

This program helps in understanding how one base class can be inherited by multiple derived classes.
