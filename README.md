# Object-Oriented Programming with C++

## Unit II - Inheritance

This repository contains the C++ programming practicals completed as part of the Unit II coursework for Object-Oriented Programming with C++.

The programs demonstrate different concepts of inheritance, constructors, polymorphism, abstract classes, friend classes, nested classes, and simple real-world applications.

## Programs Included

| No. | Program                          | Description                                                           |
| --- | -------------------------------- | --------------------------------------------------------------------- |
| 01  | Basic Single Inheritance         | Demonstrates inheritance between a base class and derived class.      |
| 02  | Protected Member Access          | Demonstrates the use of protected members in inheritance.             |
| 03  | Public and Private Inheritance   | Demonstrates different inheritance modes and accessibility.           |
| 04  | Multilevel Inheritance           | Demonstrates inheritance through multiple levels.                     |
| 05  | Hierarchical Inheritance         | Demonstrates multiple derived classes inheriting from one base class. |
| 06  | Multiple Inheritance             | Demonstrates a class inheriting from two base classes.                |
| 07  | Multiple Inheritance Ambiguity   | Demonstrates ambiguity and its resolution using scope resolution.     |
| 08  | Constructor and Destructor Order | Demonstrates the order of constructor and destructor execution.       |
| 09  | Parameterized Base Constructor   | Demonstrates passing values to a base class constructor.              |
| 10  | Function Overriding              | Demonstrates virtual functions and function overriding.               |
| 11  | Abstract Class                   | Demonstrates abstract classes and pure virtual functions.             |
| 12  | Virtual Base Class               | Demonstrates virtual inheritance and diamond inheritance.             |
| 13  | Friend Class                     | Demonstrates access to private members using a friend class.          |
| 14  | Nested Class                     | Demonstrates a class defined inside another class.                    |
| 15  | Vehicle Rental System            | A simple mini-project using inheritance and polymorphism.             |
| 16  | Employee Payroll System          | A simple payroll system using an abstract base class and overriding.  |
