# Program 01 - Basic Data Types

## Aim
To understand and use basic C++ data types such as int, char and float.

## Description
This program stores a student's roll number, grade and fee amount using different basic data types and displays them.

## Expected Output
```
Roll No: 101
Grade: A
Fee: 12500.5
```

## Concepts Used
- int
- char
- float
- cout
- Basic variable declaration
