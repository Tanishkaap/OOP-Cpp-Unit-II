# Program 13 - Friend Class

## Aim

To understand the use of a friend class in C++.

## Concept Used

* Friend Class
* Private Members
* Special Access Permission
* Encapsulation

## Description

This program demonstrates how a friend class can access private members of another class.

The `Account` class contains a private balance. The `Auditor` class is declared as a friend class, allowing it to access the private balance.

## Expected Output

```text
Balance: 5000
```

## Learning Outcome

This program helps in understanding how friend classes can be given special permission to access private data.
