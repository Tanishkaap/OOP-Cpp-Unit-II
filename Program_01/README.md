# Program 01 - Basic Single Inheritance

## Aim

To implement basic single inheritance in C++ using a base class and a derived class.

## Concept Used

* Single Inheritance
* Base Class
* Derived Class
* Protected Data Member
* Constructor
* Member Functions

## Description

This program demonstrates how a derived class inherits the properties and functions of a base class.

The `Person` class acts as the base class, while the `Student` class inherits from `Person`. The student's name is handled by the base class and the roll number is handled by the derived class.

## Expected Output

```text
Name: Amit
Roll Number: 101
```

## Learning Outcome

This program helps in understanding the basic concept of inheritance and how a derived class can reuse the members of a base class.
