# Program 02 - Protected Member Access

## Aim

To understand the use of the protected access specifier in inheritance.

## Concept Used

* Protected Members
* Inheritance
* Base Class
* Derived Class
* Member Functions

## Description

This program demonstrates how a protected data member of a base class can be accessed directly inside a derived class.

The `Employee` class contains the protected member `name`, which is accessed by the `Developer` class.

## Expected Output

```text
Name: Neha
Programming Language: C++
```

## Learning Outcome

This program helps in understanding how protected members provide access to derived classes while restricting direct access from outside the class.
