# Program 09 - Parameterized Base Constructor

## Aim

To understand how a derived class can pass values to a parameterized constructor of a base class.

## Concept Used

* Parameterized Constructor
* Inheritance
* Constructor Initialization List
* Base Class Constructor

## Description

This program demonstrates how a derived class can call the parameterized constructor of its base class using an initializer list.

The `Student` class passes the student's name to the `Person` base class constructor.

## Expected Output

```text
Name: Kiran
Roll Number: 24
```

## Learning Outcome

This program helps in understanding how constructors of base and derived classes work together.
