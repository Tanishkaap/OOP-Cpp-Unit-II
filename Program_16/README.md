# Program 16 - Employee Payroll System

## Aim

To develop a simple employee payroll system using an abstract base class and function overriding.

## Concept Used

* Abstract Class
* Pure Virtual Function
* Inheritance
* Function Overriding
* Runtime Polymorphism
* Mini Project

## Description

This mini-project demonstrates a simple employee payroll system.

The `Employee` class acts as an abstract base class. `PermanentEmployee` and `ContractEmployee` inherit from it and provide their own implementation for calculating salary.

## Features

* Store employee information
* Calculate salary
* Display employee pay slip
* Handle different types of employees

## Learning Outcome

This program demonstrates how abstract classes and overriding can be used to build a simple real-world payroll system.
