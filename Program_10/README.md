# Program 10 - Function Overriding

## Aim

To implement function overriding using virtual functions in C++.

## Concept Used

* Function Overriding
* Virtual Function
* `override` Keyword
* Runtime Polymorphism

## Description

This program demonstrates how a derived class can provide its own implementation of a function already defined in the base class.

The `Vehicle` class contains the virtual function `move()`. The `Car` and `Boat` classes override this function according to their own behavior.

## Expected Output

```text
Car moves on roads
Boat moves on water
```

## Learning Outcome

This program helps in understanding function overriding and the role of virtual functions in runtime polymorphism.
