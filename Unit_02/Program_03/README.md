# Program 03 - Public and Private Inheritance

## Aim

To understand the difference between public and private inheritance in C++.

## Concept Used

* Public Inheritance
* Private Inheritance
* Access Specifiers
* Base Class
* Derived Class

## Description

This program demonstrates two different modes of inheritance.

`PublicDerived` inherits from the base class using public inheritance, while `PrivateDerived` uses private inheritance.

The program shows how the accessibility of inherited members changes depending on the inheritance mode.

## Learning Outcome

This program helps in understanding how public and private inheritance affect the accessibility of base class members in a derived class.
