# Program 15 - Vehicle Rental System

## Aim

To develop a simple vehicle rental system using inheritance and runtime polymorphism.

## Concept Used

* Inheritance
* Function Overriding
* Virtual Functions
* Runtime Polymorphism
* Mini Project

## Description

This mini-project demonstrates a simple vehicle rental system.

The `Vehicle` class acts as the base class, while `Car` and `Bike` are derived classes. Each type of vehicle calculates its rental amount according to its own implementation.

## Features

* Display vehicle details
* Calculate rental amount
* Support different types of vehicles
* Use inheritance and virtual functions

## Learning Outcome

This program shows how inheritance and polymorphism can be applied to a simple real-world vehicle rental system.
