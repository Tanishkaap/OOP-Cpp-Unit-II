# Program 05 - Class and Object

## Aim
To understand the declaration of a class, creation of an object and use of class members.

## Description
The Student class contains name and age as data members and a show() member function. An object is created in main() and used to display the student's details.

## Expected Output
```
Amit 20
```

## Concepts Used
- Class
- Object
- Data members
- Member function
